# 好友年报 · 微信小程序

把两个人的聊天记录变成一份有温度的「年度报告」：谁更话痨、几点最活跃、高频词、亲密瞬间、年度称号，一键生成分享海报。

> 所有分析都在**手机本地**完成，聊天内容不会上传到任何服务器。

## 功能

- **📂 导入聊天记录模式**：粘贴或选择微信导出的聊天记录（JSON / TXT），自动识别双方身份，生成真实数据报告
- **📝 手填问答模式**：没有聊天记录也能玩，回答 7 个问题生成趣味版报告
- **📊 七页报告**：数字总览 / 24 小时活跃柱状图 / 高频关键词 / 亲密瞬间 / 年度称号 / 总评语
- **🎁 Canvas 分享海报**：一键生成 640×1000 海报，保存到相册或分享给好友

## 快速开始

1. **安装微信开发者工具**（Mac/Windows）：
   <https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 打开开发者工具 → 「导入项目」→ 选择本目录 `friend-year-report`；
   AppID 用测试号即可（项目里已配置 `touristappid`，游客模式可直接预览）。
3. 点击「编译」，即可在模拟器中体验；点「预览」扫码可在真机运行。
4. 想体验导入模式：微信电脑版 → 打开好友聊天窗口 → 右上角「···」→ 聊天记录 → 导出（TXT 或 JSON）→ 把文件发到手机（如文件传输助手）→ 在小程序里「从微信聊天中选择文件」或直接粘贴内容。

## 聊天记录支持格式

| 格式 | 说明 |
| --- | --- |
| JSON | 微信电脑版导出的 JSON（含 `create_time` / `sender_id` / `text` 字段），或任何 `[{text, sender, time}]` 结构的消息数组 |
| TXT | 微信导出的 TXT（`———— 2026-10-24 ————` 日期行 + `01:02 昵称：内容` 消息行） |

引擎会自动猜测「我」是谁（识别「我通过了你的朋友验证请求」或 `from_self` 字段），也可以手动点选。

## 发布流程

1. 注册小程序账号（个人主体即可）：<https://mp.weixin.qq.com> → 获取 AppID，替换 `project.config.json` 中的 `appid`。
2. **隐私协议声明**（必须）：登录 mp 后台 → 设置 → 服务内容声明 → 用户隐私保护指引，声明使用 **「选择聊天中的文件」**（对应 `wx.chooseMessageFile`）和 **「保存图片到相册」**（对应 `wx.saveImageToPhotosAlbum`）。
3. 开发者工具点「上传」→ mp 后台「版本管理」提交审核 → 审核通过后发布。
4. 建议类目：工具 → 效率 / 生活服务。注意：聊天记录不会被上传，服务端零成本，无需备案。

## 网页版（每个人打开就能用）

不想等小程序发布？项目附带一个**单文件网页版** `../web/index.html`：打开即用，支持上传/粘贴聊天记录、手填问答、演示数据、生成并下载分享海报，与小程序共用同一套分析引擎。托管到任意静态空间即可分享链接给所有人。详见 [`../web/README.md`](../web/README.md)。

## 常见问题

- **解析失败**：确认粘贴的是完整导出内容；JSON 需以 `[` 开头（数组），TXT 需包含 `———— 日期 ————` 行。
- **小程序内无法直接读取微信聊天记录**：微信不开放该 API，因此采用「用户主动导入」设计，这是目前唯一合规可行方案。
- **主包大小**：真实聊天记录无需打包进小程序（2MB 主包限制不影响本项目）。
- **海报生成失败**：iOS 需允许相册权限；海报 Canvas 为离屏绘制，失败请重试一次。
