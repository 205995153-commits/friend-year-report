# 好友年报 · 网页版

**一个 HTML 文件，每个人都能用。** 打开即用：上传或粘贴微信聊天记录（JSON / TXT），或回答几个问题，就能生成一份好友年度报告，并下载分享海报。

- ✅ 纯前端、零依赖、零服务器：所有分析在你自己的浏览器里完成，聊天内容**不上传**任何地方
- ✅ 手机、电脑浏览器都能用（手机体验最佳）
- ✅ 与微信小程序版共用**同一套分析引擎**（`friend-year-report/utils/analyzer.js`），结果完全一致

## 怎么用

### 方式一：直接打开（自己用）

双击 `web/index.html`，或用浏览器打开它即可。**没有任何文件？点「用演示数据试试」**，内置了 45 天 × 780 条示例聊天记录。

### 方式二：分享给所有人（推荐）

把 `index.html` 托管到任意静态空间，把链接发给任何人：

| 平台 | 步骤 |
| --- | --- |
| GitHub Pages | 新建仓库 → 上传 `web/index.html` → Settings → Pages → 选分支保存，获得 `https://你的名字.github.io/仓库名/` |
| Vercel / Netlify | 把 `web` 目录拖进网站即可一键部署，自动生成 `https://xxx.vercel.app` 链接 |
| 任意静态空间/对象存储 | 上传 `index.html` 即可 |

> 提示：微信里直接发送 .html 文件通常无法打开，所以建议**托管后分享链接**，对方点开就能用。

## 功能

1. **📂 导入聊天记录**：点击选择 / 拖拽 / 粘贴微信导出的 JSON 或 TXT → 自动识别双方身份（可手动点选）→ 生成真实数据报告
2. **📝 手填问答**：没有聊天记录也能玩
3. **🎲 演示数据**：一键体验完整流程
4. **📊 七页报告**：数字总览 / 24 小时活跃柱状图 / 高频关键词 / 亲密瞬间 / 年度称号 / 总评语（支持滑动、按钮、键盘 ← → 翻页）
5. **🎁 分享海报**：Canvas 生成 640×1000 海报 → 下载图片，手机上支持直接调起系统分享

## 聊天记录格式

- **JSON**：微信电脑版导出的 JSON（`create_time` / `sender_id` / `text` 字段），或任意 `[{text, sender, time}]` 数组
- **TXT**：微信导出 TXT（`———— 2026-10-24 ————` 日期行 + `01:02 昵称：内容`）

导出方法：微信电脑版 → 好友聊天窗口 → 右上角「···」→ 聊天记录 → 导出。

## 文件说明与维护

```
web/
├── index.html           # 成品（直接使用/部署）
└── index.template.html  # 模板（UI 与交互逻辑）
scripts/
└── build_web.py         # 构建脚本：内嵌同源引擎 + 生成演示数据
```

- **改 UI**：编辑 `web/index.template.html`，然后运行 `python3 scripts/build_web.py`
- **改分析逻辑**：编辑 `friend-year-report/utils/analyzer.js`（小程序与网页版同步生效），再运行构建脚本
- 构建脚本会把引擎代码内嵌进 HTML，保证**网页版与小程序版永不分叉**
